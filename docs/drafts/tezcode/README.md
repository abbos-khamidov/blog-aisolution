# TezCode: статус материалов

Владелец (AISOLUTION) дал добро на статьи по TezCode 2026-10-23. Они опубликованы как **партнёрские материалы редакции AISOLUTION**
на публичных описаниях продуктов (tezcode.dev и aisolution.uz/partnery/tezcode), без метрик и цифр, которых нет в открытых источниках:

- `content/ru/ai-office-12-agentov-po-otdelam.mdx`
- `content/ru/ai-software-factory-gotovyj-produkt-kastom-nadstrojka.mdx`

Подпись `author: "aisolution"`: правило блога (claude.md, п.3) запрещает фиктивное авторство, а своего автора TezCode не назвал.

Чтобы статьи вышли за подписью TezCode:
1. TezCode называет автора (имя, роль, фото, ссылки) и добавляет свои цифры и позиции в ответы на вопросы из брифов `01-*.md` и `02-*.md`.
2. Автор добавляется в `lib/authors.ts`, `author` в статьях заменяется, цифры вносятся только с подтверждением TezCode.
