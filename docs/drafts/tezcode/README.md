# Материалы от TezCode: порядок работы

Правило блога (claude.md, п.3): `author` во фронтматтере всегда реальный автор, фиктивного авторства нет.
Поэтому эти два материала не лежат в `content/` и не собираются. Они ждут TezCode.

Как довести до публикации:
1. TezCode читает бриф, отвечает на вопросы в конце каждого файла своими словами и цифрами, которые готовы публиковать.
2. TezCode называет автора (имя, должность, фото, ссылки). Мы добавляем его в `lib/authors.ts` с `affiliation` TezCode.
3. Мы оформляем статью в `content/ru/` с этим автором, `draft: true`, TezCode проверяет финальную версию.
4. Публикуем через PR.

Что уже публично известно и можно использовать без подтверждения: описание на странице партнёра
https://aisolution.uz/partnery/tezcode (AI Office, RAOS, CoreMed, WorkControl) и на сайте tezcode.dev.
Всё остальное требует подтверждения TezCode.
